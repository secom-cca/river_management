# Archive

現在の主系統では使っていない旧版・Vensim生成物を保管しています。
再現用の履歴資料であり、現行環境での動作は保証していません。

- `models/`: 旧PySD/Vensimモデルとバックアップモデル
- `scripts/`: `to3`、`to6` までの旧実行スクリプト
- `vensim_calibration/`: Vensim最適化・較正時の設定、ログ、中間出力
- `data/`: 旧モデルが参照していた入力データ

現行のモデルと実行スクリプトは、リポジトリ直下の
`River_management_xls_to6.py` と `run_vensim_with_pysd_to7_para.py` です。
